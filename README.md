# Guess the flower game

### Project Overview
A responsive flower guessing game built with JavaScript logic, where players identify flowers, track their score, and use limited chances to win. The game includes interactive feedback and sound effects for correct and incorrect guesses.


### Live Demo
[View the Website](https://guesstheflowernat.vercel.app/)
### Video Preview
[Watch the Website Demo](https://youtu.be/Be4QYNiJ564)


## Key Features

- Guess different flowers
- Randomly select flowers during gameplay
- Validate player guesses
- Track the player's score
- Use limited chances
- Provide feedback for correct and incorrect guesses
- Play sound effects for correct and incorrect answers
- Restart the game
- Responsive design

## Installation
1. Clone the repository
```bash
git clone https://github.com/Natalie31706-code/guesstheflowernat.git
```

2. Navigate to the project folder
```bash
cd guesstheflowernat
```

3. Open index.html in your web browser.


## Project Purpose
This project was built to practice and demonstrate core front-end web development concepts using HTML, CSS, and JavaScript while creating an interactive browser-based game. It focuses on implementing JavaScript game logic, user input handling, randomized content, score and chances management, interactive feedback, and audio effects.
